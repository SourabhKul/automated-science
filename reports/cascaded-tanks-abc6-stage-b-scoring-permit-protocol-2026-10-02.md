## Existing boundary and intended chain

The runner already reloads the Stage A execution's verified training evidence, reads all 48 ordered status receipts and terminal summary, publishes and rereads one target-free forecast artifact, then repeats the status/summary/forecast readback immediately before calling `score_deferred_abc6_synthetic` (`scripts/run_cascaded_tanks_abc6_synthetic.py:520-583`). The scorer currently checks sources, evidence and forecast, creates its anchored O_EXCL reveal marker, then mints the private target handoff (`core/real_data/cascaded_tanks_abc6_scoring.py:2384-2600`). The marker controls local one-use reveal but does not prove that the watchdog authorized scoring.

The authority already has `create_runner_handoff`, `activate_scoring`, and a sealed `ABC6ScoringPermit`, but none is wired into that runner/scorer path. Handoff currently checks digest shapes only; it does not bind Stage A's exact registered execution, grant/run/manifest/root or receipt values. A failed scoring activation is already one-use because `activation_attempted` is set before handoff validation. Public replay remains terminal-v3-only while watchdog emits v4; neither code nor this stage establishes final replay.

## Stage B1 frozen fake-only changes

1. **Runner handoff point.** Only after the runner's existing final fresh status/summary and forecast-artifact revalidation, construct exactly 48 `(case_index, component, sha256)` entries in frozen order (index 0..23, each fit then baseline). Use the freshly reread bytes' SHA-256, not cached or caller-supplied values. Call `authority.create_runner_handoff(execution, statuses, summary_sha256, forecast_sha256)` directly in `run_cascaded_tanks_abc6_synthetic`; immediate-frame role validation must remain exact. Handoff creation is a one-use attempt: record attempted before validating; an invalid or partial handoff cannot be replaced under the same authority/run ID.
2. **Execution and evidence binding.** The authority accepts the handoff only if `execution is` the exact Stage A object registered to this authority, and its grant/run/manifest/anchored receipt-root identity still matches live bindings. Compare all 48 reread status digests and summary digest to the complete execution's durable status/summary identity, not merely tuple shape. The forecast digest must match the runner's freshly reread artifact identity and the frozen target-free roster; Stage B1 may rely on the runner's established publication/readback and scorer's independent recomputation, but no stale cached digest may bypass either. Seal the handoff to this authority and exact execution object. `activate_scoring()` validates that same handoff and exact registered execution, completed 24 issued and consumed case permits, and one-use phase state; failed activation remains terminal.
3. **Scorer entrypoint.** Make `scoring_permit` a required keyword-only `ABC6ScoringPermit` argument to `score_deferred_abc6_synthetic`. After shape/type checks required to identify the permit and execution, its first supervised action directly calls `scoring_permit.consume(execution)` in the frozen scorer frame. The consume method verifies live authority, exact registered execution identity, grant/run/manifest/anchored root, activated handoff, then atomically marks `score_consumed` and the permit used before any source/evidence/forecast check, reveal marker creation or prospective-target materialization. A wrong/cross-authority execution or replayed permit must fail before marker or target materializer; an attempted valid scoring call that later fails is terminal even if no marker was written. Pass authority metadata to the existing **deferred score receipt** only through the permit when that receipt is written, never through caller-supplied fields. That writer runs after marker creation and cannot prove a pre-marker failure.
4. **Reveal gate.** Keep the existing anchored marker, readback and post-marker failure semantics. Internal target materialization must be reachable only after successful permit consumption and the marker. Preserve the fixed one-shot roster and all-particle failure rules; this stage does not change scientific scores, ABC, source pins, runtime controls, or final dataset boundaries.
