## Scientific and reference decision

Thermal relaxation could test parameter transfer across separately recorded
runs, but the checked teaching sources did not establish the required raw
repeat set or independently known baseline/initial state/noise. The existing
Gaussian ODE reference is fixed to exp(-k*t), with unit initial state, zero
asymptote and common known scalar sigma. The generic RK4 helper's separate
initial state is not an input to that reference. No thermal source or pilot
is selected. Normalization cannot make uncertain calibration disappear.

Primary derived the first-order thermal-ratio covariance for i,j>0, including
shared initial and ambient measurement terms. The approximation needs small
errors and a safely nonzero denominator; its exact ratio distribution need
not be Gaussian. R0 is identically one when readings are reused, not an
independent noisy point. This is algebra, not a calculation on visible rows.

Independent integer Poisson bins with means A*Lambda_j(lambda), known
exposures and no additive background have a conditional multinomial target
when total count is fixed. Amplitude cancels conditionally, not by general
Bayesian marginalization. This leaves a tractable scalar shape likelihood
in principle, not an absolute-rate prediction or checked implementation.
Zero total count is uninformative. Background, event loss, uncertain exposure,
dead time, pile-up and processed peak areas need a different or expanded
contract. The Ag metadata does not establish the needed raw-count conditions.
Do not infer independent physical sources from detector/sequence labels.
The published half-life is prior work, not our result or fit target.

The operator verified the ordinary Gaussian target's exact input restrictions
and found no explicit Poisson-count reference. The ODE helper's Poisson
terms are a noncentral-chi-square series, not a count likelihood. Primary's
targeted source read also found the sibling finite-epsilon CDF hard-codes
df=4 despite a broader shape check. The ordinary Gaussian branch returns
before that CDF. The default completed control has four times, so this is
not evidence invalidating it. No n!=4 reuse or closed-source repair is
approved. A formal review held the initial screen only for omission of this
caveat; primary added it before final approval. No source or test changed.
