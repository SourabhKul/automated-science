# Cascaded Tanks six-parameter synthetic ABC control — proposal

**Status: independently reviewed scientific predeclaration; implementation, code review, immutable manifest and run approval remain separate gates.** This is a synthetic methods control, not a fit to the public tank data and not a mechanism-discovery result. It follows the independently replayed short/long-recovery sensitivity control in `reports/research-ledger/2026-09-27T2010Z.md`. Its question is whether a checked ABC-SMC reference can fit and forecast when `a,c,p,x1_0,x2_0,H` vary, whether the longer recovery changes *practical* recovery/uncertainty diagnostics, and whether wrong-family or omitted-observation effects remain visible. Local Jacobian rank alone cannot answer those questions. No real archive, real `yEst[768:1024]`, official `uVal/yVal`, Qwen, or other LLM may be accessed.

## Synthetic systems and data boundary

Use only the reviewed deterministic S0/O2/C2 simulator and `run_cascaded_tanks_synthetic_abc_smc` with the checked Gaussian reference kernel; fit only O2 and C2 in this control. Pre-transition output convention, nonnegative state and ceiling/floor semantics remain unchanged. Truth A is O2 with `(a,c,p,x1_0,x2_0,H)=(0.50,0.40,0.50,0.50,0.50,3.0)`; truth B is C2 with `(0.54,0.36,0.46,0.25,0.75,3.2)`. `H` is a report label; the exact sixth simulator/wrapper key is `ceiling`, and the API parameter insertion order is `(a,c,p,x1_0,x2_0,ceiling)`. These are two constructed systems, not independent physical replications. The common crossing input L is exactly 24 samples at `u=8.0` followed by 180 at `u=0.0`; S is its first 78 samples. Construct the entire 204-step *training* truth path once per family. Declare the 60-step prospective **input only** before fitting: 12 samples at `u=3.0`, 12 at `u=8.0`, then 36 at `u=0.0`. Fit S sees only outputs 0–77 and inputs 0–77; fit L sees outputs 0–203 and inputs 0–203. Both may know the intervening input zeros, but not outputs 78–203 when S is fitted. Before its common-time prospective forecast, an S-fitted particle must be propagated through those 126 known zero inputs without observing their outputs. Do not generate, materialize, hash or read the 60 prospective truth outputs until a durable post-fit gate verifies all 24 fit and baseline status receipts; those targets are never used to calibrate priors, thresholds, fitting, baseline settings, or model choice.

For each truth, create four *measurement-noise* realizations of the 204 training outputs by adding iid `Normal(0,0.05)` with `np.random.default_rng` seeds 8100–8103 for A and 8200–8203 for B. S and L with the same replicate suffix share the same noise prefix; all four suffixes are fitted in both windows for within-truth paired descriptive comparisons. They remain one synthetic system per family; four noisy measurements do not amount to four independent mechanisms or interventions. The prospective 60-step target is noiseless, so particle envelopes cover latent/mean-output trajectories, **not** new measurement noise. Report timepoint inclusion as a dependent-trajectory diagnostic, not calibrated observation coverage.

Two additional controls are fixed separately. N is a no-crossing C2 truth with A's common parameters and `H=1000`, 24 samples at `u=8` then 180 at `u=0`, with no measurement noise. Fit O2 and C2 but make no family choice from the N fit; the earlier sensitivity control established an exact output tie only at that truth/input and local zero `H` sensitivity. N has **no prospective target or score** in this protocol. M is a deliberately misspecified C2-B observation on the 204-step L input with noiseless simulator output plus `0.15*u[k]` at each training step; its 60-step future observation also adds `0.15*u[k]`, generated only after the post-fit gate. The fitted simulator has no feedthrough. Fit both C2 and O2; no truth-parameter coverage claim applies to wrong-family or misspecified fits.

## Frozen fit roster and priors

Run the following 24 fits in this order, with case index `i=0..23`. Each fit receives separate calibration RNG seed `9000+i` and ABC seed `10000+i`. The prospective target must remain deferred until **all** training fits/baselines and their fit-status receipts have been durably written. Cases 0–7 use replicate suffix 0; cases 12–23 add suffixes 1–3 for paired same-family S/L fits. Do not interpret incomplete wrong-family fits as evidence for the true family.

| i | Truth / fit input / replicate | Fitted family |
| ---: | --- | --- |
| 0–3 | A/S/0, A/S/0, A/L/0, A/L/0 | O2, C2, O2, C2 |
| 4–7 | B/S/0, B/S/0, B/L/0, B/L/0 | C2, O2, C2, O2 |
| 8–9 | N/noiseless | O2, C2 |
| 10–11 | M/noiseless feedthrough | C2, O2 |

| 18–23 | B/S/1, B/L/1, B/S/2, B/L/2, B/S/3, B/L/3 | C2 each |

For crossing S/L and M fits, use independent uniform prior support boxes in the exact wrapper order `(a,c,p,x1_0,x2_0,ceiling)`: `[0.40,0.60]`, `[0.30,0.50]`, `[0.40,0.60]`, `[0,1]`, `[0,1]`, `[2.6,3.6]`. For N replace only the `ceiling` box with `[900,1100]`; O2's complete rectangle satisfies `upper(x2_0) <= lower(ceiling)`. The wrapper/reference support and log density include the endpoints, while NumPy uniform prior draws fall in a half-open interval almost surely; the endpoint distinction has zero prior mass but matters for proposal/baseline validation. All declared truths are interior. These are synthetic local boxes, **not** numeric priors for real tanks. Use full-training-trajectory RMSE in simulated output units, no summary compression, and the checked normalized-unit-cube Gaussian proposal and prior-over-mixture importance weights without BDSS. Retain every simulation failure category and the reference's per-population counts of out-of-support proposals, proposal failures and weight failures, plus seeds/hashes for replay; the current reference does not retain coordinates for each rejected proposal.

Before each fit, draw exactly 256 independent prior points using its calibration seed, simulate the fit-length input, and calculate full-trace RMSE to that fit's noisy or deterministic training observation. These 256 draws calibrate thresholds only; they are not accepted particles or reused in ABC populations. Charge all calibration simulator calls to total compute. Define `epsilon_0` and `epsilon_1` as the left-inverse empirical 25th and 10th percentiles of the **finite** 256 discrepancies, using sorted zero-based indices `ceil(0.25*n)-1` and `ceil(0.10*n)-1` for `n` finite values; record `n`, rejected/failure counts and exact thresholds. If fewer than 256 finite values occur, or either threshold is nonfinite/nonpositive, mark the fit unresolved before ABC; do not replace draws or change quantiles. Otherwise run two populations of 48 particles with those fixed non-increasing thresholds and at most 4,096 proposals per population. Preserve incomplete populations as diagnostics with **no terminal posterior** and no all-particle forecast. This data-dependent tolerance rule is a declared algorithm component, not a claim that ABC samples an exact Gaussian-noise posterior. Different models/cases can have different thresholds; never use their acceptance rates or weighted particles as Bayes factors or comparable model probabilities.

## Cost-matched baseline and deferred diagnostics

For each fitted model/case, run a deterministic, SciPy-free, bounded coordinate pattern-search baseline on the same normalized prior box and training RMSE. Its maximum simulator-call allowance is that case's *realized* 256 calibration calls plus **the sum over every completed or incomplete reference population** of `population.diagnostics.simulated + population.diagnostics.failed_simulations`; the wrapper's top-level diagnostics describe only the last population and must not be used as a total. `proposed` includes support rejects with no simulator call. Record attempts and support rejects separately. Charge each baseline objective evaluation once even when its simulator trajectory fails; use `+inf` objective for a failed trace and no clipping. Report both simulator-call counts and reserved step evaluations (`calls × 78` or `calls × 204`) plus actual completed steps for failed traces. Generation and prospective forecasts are accounted separately from fitting. The realized ABC cost determines baseline budget but **no ABC fit values, forecasts, errors or final outcomes** tune the baseline algorithm.

The baseline evaluates center first, then all `2^6` box corners in lexicographic bit order (the reference support includes both endpoints), caching each unique coordinate vector and its objective. Freeze the start order by sorting those 65 evaluated points by `(RMSE, normalized-coordinate lexicographic order)`, with failed `+inf` values last. For each start in that frozen order, reset the local mesh to 0.25 and current point to that start. Poll `+` then `−` for each coordinate in fixed parameter order around the current point, clipping polls to `[0,1]`; reuse cached evaluations without charging another call. Finish a full poll before choosing its lowest `(RMSE, coordinates)` point; move to it if it ranks below the current point, otherwise halve mesh. A local search terminates when its mesh becomes strictly less than `2^-10`, then the next frozen start begins. If the call allowance expires mid-poll, stop immediately, record the partial-poll position, and use the best **evaluated** point across all starts as the baseline result; no unvisited candidate is inferred. Stop if every start terminates, even if allowance remains, and report under-use. Every objective failure has value `+inf`; if all evaluated points fail, there is no valid baseline point or forecast. Save all unique evaluated normalized points, objective/failure category, poll/restart state, call and step accounting. The baseline is a bounded optimization control, not an uncertainty estimator.

For every complete **non-N** ABC fit, reconstruct the latent state for **each** terminal particle and, when one exists, the baseline best point over the observed training input. For S, propagate 126 unobserved zero inputs to the common time 204; for L/M, the fit ends at that time. After the durable post-fit gate, generate the common 60-step A/B truth targets and M's feedthrough target from the frozen true terminal states; hash them before scoring. Forecast every particle and any valid baseline point through the common 60-step prospective input from their estimated states; one nonfinite or failed particle suppresses the entire ABC aggregate forecast, without dropping particles. Save full particle trajectories and unchanged weights under ignored artifacts. Compare prospective RMSE for the baseline coherent trajectory, ABC pointwise weighted-mean forecast (squared-loss-matched ensemble), and ABC pointwise weighted-median forecast. Both ABC pointwise summaries are generally not single simulator trajectories; do not equate them to the baseline's coherent forecast. Use the weighted left-inverse empirical-CDF convention for ABC 5th/50th/95th pointwise intervals. Report the fraction of the 60 declared prospective targets inside the 5th–95th envelope. For A/B these are noise-free mean outputs and the fraction is a dependent-trajectory diagnostic, not calibrated observation coverage; for M the target includes feedthrough and the fraction is an observation-mismatch diagnostic, not coverage. Report terminal ESS and weighted 5th–95th parameter intervals/truth inclusion for complete **same-family, correctly specified** fits. The four paired S/L noise realizations per truth provide only a 0–4 inclusion count per parameter within each window and four paired descriptive horizon contrasts, not a reliable 90% coverage estimate or independent-system replication. For each truth and suffix 0–3, report `prospective_RMSE_S − prospective_RMSE_L` separately for the ABC weighted-mean, ABC weighted-median and baseline coherent forecasts on the same 60-point target; positive means L predicted better. If either fit or any required forecast is incomplete, report that pair’s contrast as null and do not select a favorable subset. For N report weighted `ceiling`/H 5th/50th/95th quantiles alongside the uniform-prior reference values 910/1000/1090, with no binary agreement threshold, plus mandatory mechanism abstention and no prospective score. For each M fit family, report signed `observed−predicted` training residual means separately for the coherent baseline best-point trace (if valid) and ABC pointwise weighted-mean trace (if complete); label the latter as an ensemble summary. The groups are exact indices `k∈[0,24)` (`u=8`) and `k∈[24,204)` (`u=0`). No wrong-family truth inclusion or Bayes-factor claim.
