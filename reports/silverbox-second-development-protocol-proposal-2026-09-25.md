## Question and decision

Can the already checked reference ABC-SMC kernel complete the fixed Silverbox linear and one Qwen-selected nonlinear hypotheses under a larger but still bounded transition-attempt budget, without changing priors, discrepancies, epsilon calibration, proposal weights, or data splits? The first run completed both 64-particle initial populations but exhausted 512 attempts in the second population at 58/64 linear and 42/64 nonlinear particles. Out-of-support proposals accounted for 345 and 374 attempts respectively. The failure is an operational inference-control result, not evidence for or against either physical mechanism.

The proposed sole inference-budget change is **2,048 maximum attempts per population for each family**, with the same target of 64 accepted particles. Keep 256 prior calibration draws/family, q50 then q20 train-only calibrated thresholds, 128-finite-draw gate, ABC seeds `26092511` and `26092512`, `covariance_scale=2.0`, `lambda_noise=0.01`, `nugget=1e-9`, all frozen parameter supports/scalers and divergence checks, pointwise weighted-median forecasts, 5% nonlinear promotion margin, and persistence control from `reports/silverbox-first-fit-protocol-2026-09-25.md`. Keep the 600-second total wall cap, 2 GiB additional fit-process RSS cap, one fit process, and the same source ranges. The 2,048 cap is a transparent post-failure adjustment using training-only diagnostics. It does not establish that the kernel is more efficient or calibrated; a separate matched-cost transition study is needed before considering BDSS or another proposal as an improvement.

Run one fresh, receipted workflow with a new run ID and the same exact local Qwen model, endpoint, prompt, grammar, and one-proposal/no-retry rule. Preserve the 120-second request and preflight timeouts and terminal failure behavior. The 600-second global clock starts before source verification and Qwen preflight and covers the request, calibration, ABC populations, particle forecasts, validation selection, and receipt finalization. A deadline overrun, failed request, or incomplete fit stays unresolved, without extension, fallback, or sealed scoring.
