# DREAM4 In-Silico Size-10 Source Contract

This directory holds a fixed, GPL-licensed in-silico systems-biology benchmark from the archived Bioconductor DREAM4 package version `0.99.17`.

- Package page: <https://bioconductor.statistik.tu-dortmund.de/packages/2.12/data/experiment/html/DREAM4.html>
- Fixed source URL: <https://bioconductor.org/packages/2.12/data/experiment/src/contrib/DREAM4_0.99.17.tar.gz>
- Raw package: `raw/DREAM4_0.99.17.tar.gz`
- SHA-256: `b86ecd617efa65947ecb40a374d95cbee69b69ec7a8880c338375b9d4508443d`
- SHA-1: `f5a0b56d08233d73e18839371f87dac354c92e96`
- Inner fixed table archive SHA-256: `1dede2b7578c552da2521c2ca31ebbcdaa04245eb7e54084e217d46731a871b2`

The package's nested `lightlyProcessedDownloadedData.tar.gz` contains five `insilico_size10_*` directories. Each has a `timeseries.tsv` with five finite 21-point blocks, `0..1000` in 50-unit increments, and a 90-row directed non-self `goldStandard.tsv`. The edge matrix is evaluation-only.

The archived processing notes state that a perturbation is applied through the first half of each trajectory and removed at `t=500`, but do not identify the genes targeted by each trajectory. The supported contract is therefore **recovery forecasting** conditioned on the observed state at `t=500`, scoring `t=550..1000`; it is not unseen-intervention prediction.

`manifest.json`, `recovery_splits.json`, and `baseline_results.json` are generated by `scripts/legacy/real_dream4_data_loader.py`. This is an in-silico architecture benchmark only, not an experimental-biology result or biological-mechanism claim.
